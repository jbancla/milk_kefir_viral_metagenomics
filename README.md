# Milk Kefir Viral Metagenomics

Analysis scripts for "Silent passengers: microdiversity and auxiliary gene
repertoires reveal fine-scale complexity in the milk kefir virome"
(submitted to <journal>, manuscript # <id>).

Scripts cover read preprocessing, assembly and MAG recovery, viral population
recovery, taxonomy and gene-sharing networks, host prediction, macro- and
microdiversity, auxiliary viral gene identification, and the downstream
statistics and figures.

## Repository structure
`unix_scripts/` — HPC pipeline steps, numbered by processing stage.
`r_scripts/` — R analyses and figures. Numbering is independent of the
Unix scripts and follows the project's analysis directories.
